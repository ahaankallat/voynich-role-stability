# Submission guide

Recommended preprint path:

1. Upload the repository to GitHub.
2. Submit the paper source to arXiv under `cs.CL`.
3. Use `cs.DL` only as a secondary category if the paper is framed as a manuscript data and reproducibility resource.
4. Seek feedback from computational linguistics or digital humanities researchers before journal or workshop submission.

The paper should be described as a role stability study. It should not be described as decipherment.
