# Methods

This project stops at internal role stability. It evaluates whether morphology-aware units in Voynichese preserve stable internal role assignments under multiple controls.

Covered layers:

1. Transcription evidence assumptions
2. Operational morphology
3. Token and family-level role units
4. Role stability under controls
5. Independent role recovery tests
6. Tokenization robustness checks

Excluded layers:

1. Formal grammar
2. Semantics
3. Lexical decipherment
4. Phonetic values
5. Plaintext language identification

The analysis uses threshold sensitivity, ablation checks, random role baselines, held-out validation, transcription tier robustness, section-level profiles, independent cluster induction, predictive validation, and alternate tokenization tests. The paper should be read as a bounded reproducibility study, not as a decipherment claim.
