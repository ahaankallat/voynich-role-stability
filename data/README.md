# Data

This directory contains derived project tables used to reproduce the analyses reported in the paper.

- `processed/voynich_pass26_core_token_occurrences_exploded.csv`
- `processed/voynich_pass26_corrected_functional_glossed_core_s1s2.csv`
- `processed/voynich_pass26_token_residual_function_inventory.csv`
- `processed/pass*_*.csv`
- `processed/*summary.csv`
- `processed/*catalog.csv`

Raw third-party Voynich transcription witnesses are not bundled here as newly redistributed source material. The included tables are derived research artifacts for the role-stability analysis. See `docs/DATA_SOURCES.md` for source and licensing notes.
